# Contributing

Pull requests are welcome for templates, rules, stack pages and the skills in "the engine".

Three rules:

1. Never include your own business data, or anyone else's. Placeholders must look like placeholders.
2. Skills credited to an upstream author are fixed upstream, not here. Send your patch to them and we will pull it.
3. Every file ends with a Related list, and every rule cites the incident that created it.
