# Derailers (example)

Three named ways the example operator loses a week, with the tell the agent can read from the files and the recovery move for each. This is documentation: the standup never borrows a row from here to fill an empty `derailers.md`.

| Derailer | How it shows up | Recovery move |
|---|---|---|
| Building instead of publishing | Three standups in a row with a product task as the one thing and no post published | Publish the rough draft today. One paragraph counts. |
| Polishing past good-enough | An experiment sits in `planned` for two weeks because the copy "isn't ready" | Ship the current version as the variant. The test decides, not you. |
| Inbox as the day's plan | Standup written after 10:00, or `must_be_true` is a reply to someone | Write the standup before opening mail. Reply after the one thing lands. |

If you're in a team: each person keeps their own three rows.
