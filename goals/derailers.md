# Derailers

This file is the agent's coaching instructions. The standup reads it for the protect-against line every morning; the monthly retro reads it for the derailer verdicts.

`MISSION.md` holds the year goal and the annual goals and nothing else. Coaching notes do not belong there.

A derailer is a way you lose a week that you would recognise if someone showed you the pattern. Most operators have three. Each gets a recovery move you can do in under an hour, today.

## How to find yours

1. Read your last eight weekly retros (or eight weeks of memory, if you have no retros yet). Write down every week that felt busy and moved no number.
2. For each, ask what you did instead of the thing that would have moved the number. The answer repeats. That repeat is the derailer.
3. Name it in five words or fewer, in the second person, as a habit rather than a mood. "Building instead of publishing", not "lack of focus".
4. Write the tell: the thing the agent can see in your files. A standup with no verdict. An experiment stuck in `planned`. A standup written after 10:00. If there is no observable tell, the agent cannot help, so find one.

## The universal recovery move

Every recovery move is the same move in different clothes: **the smallest version, today.** Not the plan to do it. Not the better version next week. The paragraph, the one email, the variant as it stands. A derailer feeds on the gap between "not started" and "done properly". The smallest version closes the gap in an hour and takes the derailer's food away.

Write the specific form for each derailer, but check it against the universal one. If the recovery move takes more than a day, it is a project wearing a recovery move's coat.
